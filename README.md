# Голосовой ассистент задач, напоминаний и встреч

Пользователь говорит или пишет в свободной форме («Напомни завтра в 10 утра позвонить Ивану») — ассистент понимает запрос,
сохраняет данные и отвечает текстом и голосом.

## Как запустить

Нужен Python 3.10+. Windows: двойной щелчок по **`start.bat`**. macOS/Linux: `./start.sh`.
При первом запуске программа сама доустановит библиотеки (2–5 минут) и откроет сайт `http://127.0.0.1:8000`.
Консольное окно не закрывайте — это сервер. Данные лежат в файле `assistant_data.csv` рядом (открывается в Excel).

Ключ Gemini **необязателен**. При входе на сайт появляется окно «Ключ Gemini API»: вставьте ключ
([получить](https://aistudio.google.com/apikey)) или нажмите «Пропустить». Ключ хранится только в браузере (кнопка «🔑 Ключ» вверху — сменить или удалить).
Порядок выбора: ключ из окна → ключ сервера (`GEMINI_API_KEY` в `.env` или в переменных хостинга/Docker) → локальный режим.
Если Gemini не отвечает (нужен VPN, лимит), ассистент пробует подключиться и при неудаче продолжает офлайн.

## Два режима работы (переключаются автоматически)

**Переключатель режима** вверху страницы: «Авто» (Gemini, при сбое — локально), «Онлайн» (только Gemini, при сбое — сообщение об ошибке) и «Офлайн» (Gemini не используется вообще, всё обрабатывается локально). Выбор запоминается в браузере.


| | ☁️ Облачный (Gemini) | 💻 Локальный (без интернета) |
|---|---|---|
| Когда | есть ключ и Gemini доступен | нет ключа, нет сети/VPN, регион заблокирован, лимит исчерпан |
| Распознавание речи | Gemini | faster-whisper (модель `small`, скачивается один раз в `models/`) |
| Понимание запроса | LLM | правила для русского языка (`localnlu.py`) |
| Поиск по смыслу | эмбеддинги Gemini | многоязычная модель fastembed → n-граммы + синонимы |
| Озвучка | браузер (Web Speech API, локальные голоса в приоритете) | то же |
| Точность | высокая | ниже: стандартные формулировки понимает, нетипичные — хуже |

Если Gemini не ответил за 15 секунд или вернул ошибку, запрос тут же выполняется локально, а следующие минуты облако
не опрашивается (ответ приходит без задержки). Сайт показывает текущий режим вверху страницы, а ответы локального режима
помечены. **Предупреждение:** из России Gemini обычно доступен только через VPN; без VPN запрос будет обработан локально.
Для работы офлайн локальные модели нужно один раз скачать (в фоне при первом запуске, нужен интернет).

## Что реализовано

| Требование ТЗ | Как работает |
|---|---|
| Создание задачи / напоминания | «Напомни мне завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт», «Поставь задачу купить билеты до конца недели» |
| Создание встречи | «Добавь встречу с командой завтра в 15:00», «В четверг в 11 у меня встреча с дизайнером» |
| Список за период | «Что у меня сегодня?», «Какие планы на сегодня?», «Покажи мои встречи на сегодня», «Какие задачи на завтра?», «Что запланировано на эту неделю?» — разные формулировки дают одно действие |
| Поиск старых записей | «Найди задачу про презентацию», «Когда у меня была встреча с Иваном?», «Я когда-то ставил задачу по договору, найди её» |
| Относительные даты | сегодня, завтра, послезавтра, день недели, «через два часа», «на следующей неделе», «до конца недели», «25 октября» |
| Уточняющие вопросы | «Поставь встречу с Иваном завтра» → «На какое время поставить встречу?» → «В три» / «8 утра» / «на 8 утра» (работает и в локальном режиме; непонятный ответ переспрашивается, а не превращается в задачу) |
| Хранение | CSV: тип, название, дата, время, статус, дата создания; данные сохраняются между запросами |
| Голосовой сценарий | голос → распознавание → обработка → действие → ответ текстом и голосом; есть и текстовый ввод |
| **Правка и удаление на сайте** | у каждой записи ✏️ (название, тип, дата, время) и 🗑 (с подтверждением) |
| **Отметка выполненной** | галочка на сайте или голосом: «Отметь задачу про договор выполненной» |
| **Семантический поиск** | поле поиска на сайте и голосовой поиск: «договор» находит «Подписать контракт» |
| **Изменение и удаление голосом** | «Перенеси встречу с Иваном на пятницу в 15:00», «Удали задачу про договор», «Удали последнюю запись». Удаление и перенос выполняются только при совпадении по словам, при неоднозначности ассистент переспрашивает |
| Контекст диалога | ответы на уточняющие вопросы достраивают запись; «А перенеси её на завтра», «Отметь её выполненной» относятся к последней записи, о которой шла речь |
| Конфликт встреч | при встрече на то же время ассистент предупреждает |
| Несколько пользователей | режим `MULTI_USER=1`: у каждого браузера свои записи (включён в Dockerfile) |

## Архитектура

```
Браузер (app/static/index.html)  запись голоса, чат, список записей: правка / удаление / галочка / поиск
        │  /api/voice · /api/message · /api/items · /api/search
app/server.py       HTTP-слой (FastAPI), без логики
app/assistant.py    бизнес-логика: проверки, уточнения, дубли, конфликты, выбор режима, ответы
   ├── app/llm.py          Gemini: речь + смысл за один вызов, эмбеддинги; «предохранитель» при сбоях
   ├── app/stt_local.py    faster-whisper (офлайн-распознавание речи)
   ├── app/localnlu.py     правила разбора русских фраз (офлайн-замена LLM)
   ├── app/search.py       поиск: слова → эмбеддинги Gemini → fastembed → n-граммы
   ├── app/storage.py      CSV: чтение, запись, правка, удаление
   └── app/textutil.py     даты, русские формулировки
app/tests/                 54 теста без сети (python -m unittest discover -s tests, из папки app)
```

## Принятые решения

- **LLM только разбирает запрос, действия выполняет код.** Обязательные поля (у встречи и напоминания — дата и время),
  дубли, прошедшее время и конфликты проверяются в коде и покрыты тестами. Поэтому облачный и локальный режимы дают одинаковое поведение.
- **Речь и смысл — одним вызовом Gemini** (меньше задержка и мест для сбоя). В локальном режиме: Whisper → правила.
- **Автоматический запасной режим** вместо ручного переключателя: проверяющему не нужно ничего настраивать.
- **Озвучка — Web Speech API браузера:** отдельная серверная библиотека синтеза не нужна, голоса ОС работают офлайн.
- **Публикация:** ключ Gemini хранится только в переменных окружения хостинга (в репозиторий и в код не попадает).
  Сервер за рубежом достучится до Gemini без VPN, проверяющему достаточно открыть ссылку.
- **CSV вместо БД:** файл виден и открывается в Excel; правка и удаление переписывают его атомарно (через временный файл).

## Публикация сайта (Docker)

`Dockerfile` готов (Render, Railway, Hugging Face Spaces и др.). Ключ задайте как секрет `GEMINI_API_KEY` в настройках хостинга.
Порт берётся из `PORT`. Файловая система бесплатных хостингов временная: записи могут пропасть при перезапуске — для демо это допустимо.
В образ ставится только faster-whisper с самой лёгкой моделью `tiny` (запасное распознавание речи без Gemini); тяжёлая модель поиска не ставится — поиск идёт по словам и n-граммам.
