# Голосовой ассистент задач, напоминаний и встреч

Пользователь говорит или пишет в свободной форме («Напомни завтра в 10 утра позвонить Ивану») — ассистент понимает запрос,
сохраняет данные и отвечает текстом и голосом. Работает онлайн (Gemini), локально на сервере и полностью автономно в браузере.

## Как пользоваться (опубликованный сайт)

Откройте ссылку на прототип — больше ничего не нужно, **VPN не требуется**. Сайт работает на сервере за рубежом (Render, Франкфурт),
у которого есть ключ Gemini (хранится в настройках хостинга, не в коде), поэтому облачный режим включается сам.
При входе можно вставить собственный ключ Gemini или нажать «Пропустить» — тогда используется ключ сервера.

## Как запустить локально

Нужен Python 3.10+. Windows: двойной щелчок по **`start.bat`**. macOS/Linux: `./start.sh`.
При первом запуске программа сама доустановит библиотеки (2–5 минут) и откроет сайт `http://127.0.0.1:8000`.
Консольное окно не закрывайте — это сервер. Данные лежат в файле `assistant_data.csv` рядом (открывается в Excel).

Ключ Gemini **необязателен**. Порядок выбора: ключ из окна на сайте → ключ сервера (`GEMINI_API_KEY` в `.env`) → локальный режим.

**Когда нужен VPN.** Только если вы запускаете ассистент **на своём компьютере в России** и хотите, чтобы он ходил в Gemini
(со своим ключом или ключом из `.env`): запросы идут с вашего IP, а Gemini из России недоступен. Без VPN ассистент не ломается —
запрос выполняется локально (режим «Офлайн»). На опубликованном сайте VPN не нужен никому.

## Режимы работы

Переключатель вверху страницы: **«Авто»** (Gemini, при сбое — локально), **«Онлайн»** (только Gemini, при сбое — сообщение об ошибке),
**«Офлайн»** (Gemini не используется). Выбор запоминается в браузере.

| | ☁️ Облачный (Gemini) | 💻 Локальный (на сервере) | 📴 Автономный (в браузере) |
|---|---|---|---|
| Когда | есть ключ и Gemini доступен | нет ключа, лимит, Gemini недоступен | нет связи с сервером |
| Речь | Gemini | faster-whisper | распознавание браузера, если оно локальное, иначе текст |
| Понимание запроса | LLM | правила для русского (`localnlu.py`) | те же правила в JS (`offline.js`) |
| Поиск по смыслу | эмбеддинги Gemini | n-граммы + синонимы | n-граммы + синонимы |
| Точность | высокая | ниже: нетипичные формулировки понимает хуже | как в локальном |

Если Gemini не ответил за 15 секунд или вернул ошибку, запрос тут же выполняется локально, а следующие минуты облако не опрашивается.
Текущий режим показан вверху страницы, ответы локального режима помечены.

## Автономный режим и сохранность данных

- Если сервер недоступен (нет интернета, сервер «спит» или перезапускается), страница сама переключается на работу прямо в браузере:
  тот же разбор фраз (`app/static/offline.js`, порт `localnlu.py`; совпадение с Python проверяет `python tests/diff_offline.py`),
  записи хранятся на устройстве. Страница открывается без сети благодаря service worker (`app/static/sw.js`) — нужно один раз зайти онлайн.
- Когда связь появляется, изменения сами отправляются на сервер (`POST /api/import`), в чате приходит сообщение.
- Бесплатный хостинг стирает данные при перезапуске: на устройстве хранится копия, и при следующем заходе записи возвращаются на сервер.
  Если очистить данные сайта в браузере, копия пропадёт — для надёжности используйте файл (ниже).
- Закрытие или обновление страницы требует подтверждения браузера.

## Файл с записями

- **«скачать CSV»** — один и тот же файл дополняется, а не плодятся копии. На компьютере (Chrome/Edge) файл выбирается один раз и
  дальше дописывается сам. На телефоне и в других браузерах программа просит выбрать прежний файл и скачивает объединённый
  (браузер может назвать его `... (1).csv` — старый удалите). Статус «выполнено» берётся из приложения.
- **«загрузить из файла»** — подгружает записи из файла, скачанного на другом устройстве: новые добавляются, у существующих
  обновляется статус (берётся из файла). Работает и без связи.
- Записи сопоставляются по типу, названию, дате и времени, а не по номеру (номера на разных устройствах разные), дубликаты не создаются.

## Что реализовано

| Требование ТЗ | Как работает |
|---|---|
| Создание задачи / напоминания | «Напомни мне завтра в 10 утра позвонить Ивану», «В пятницу нужно отправить отчёт», «Поставь задачу купить билеты до конца недели» |
| Создание встречи | «Добавь встречу с командой завтра в 15:00», «В четверг в 11 у меня встреча с дизайнером» |
| Список за период | «Что у меня сегодня?», «Какие задачи на завтра?», «Покажи мои встречи на эту неделю» — разные формулировки дают одно действие |
| Поиск старых записей | «Найди задачу про презентацию», «Когда у меня была встреча с Иваном?» |
| Относительные даты | сегодня, завтра, послезавтра, день недели, «через два часа», «на следующей неделе», «до конца недели», «25 октября» |
| Уточняющие вопросы | «Поставь встречу с Иваном завтра» → «На какое время?» → «В три» / «8 утра» (работает и локально; непонятный ответ переспрашивается) |
| Хранение | CSV: тип, название, дата, время, статус, дата создания; данные сохраняются между запросами |
| Голосовой сценарий | голос → распознавание → обработка → действие → ответ текстом и голосом; есть и текстовый ввод |
| Правка и удаление | на сайте ✏️ и 🗑 (с подтверждением); голосом: «Перенеси встречу с Иваном на пятницу в 15:00», «Удали задачу про договор» — только при совпадении по словам, при неоднозначности переспрашивает |
| Отметка выполненной | галочка на сайте или голосом: «Отметь задачу про договор выполненной» |
| Семантический поиск | поле поиска и голосовой поиск: «договор» находит «Подписать контракт» |
| Контекст диалога | «А перенеси её на завтра», «Отметь её выполненной» относятся к последней записи |
| Конфликт встреч | при встрече на то же время ассистент предупреждает |
| Несколько пользователей | `MULTI_USER=1`: у каждого браузера свои записи (включено в Dockerfile) |
| Подсказки | список доступных команд всегда виден на странице, их можно нажимать |

## Архитектура

```
Браузер  app/static/index.html (чат, список, подсказки), offline.js (автономный движок), sw.js (кэш страницы)
   │  /api/voice · /api/message · /api/items · /api/search · /api/import · /api/export.csv
app/server.py       HTTP-слой (FastAPI), без логики; ключ и режим запроса приходят в заголовках
app/assistant.py    бизнес-логика: проверки, уточнения, дубли, конфликты, выбор режима, ответы
   ├── app/llm.py          Gemini: речь + смысл за один вызов, эмбеддинги; «предохранитель» при сбоях
   ├── app/stt_local.py    faster-whisper (запасное распознавание речи)
   ├── app/localnlu.py     правила разбора русских фраз (замена LLM)
   ├── app/search.py       поиск: слова → эмбеддинги Gemini → n-граммы + синонимы
   ├── app/storage.py      CSV: чтение, запись, правка, удаление
   └── app/textutil.py     даты, русские формулировки
app/tests/                 61 тест без сети (python -m unittest discover -s tests, из папки app)
                           diff_offline.py — сравнение браузерного движка с Python на случайных фразах
```

## Принятые решения

- **LLM только разбирает запрос, действия выполняет код.** Обязательные поля, дубли, прошедшее время и конфликты проверяются
  в коде и покрыты тестами, поэтому все режимы ведут себя одинаково.
- **Речь и смысл — одним вызовом Gemini** (меньше задержка и мест для сбоя).
- **Автоматический запасной режим:** проверяющему не нужно ничего настраивать, сервис работает даже без ключа и без связи.
- **Озвучка — Web Speech API браузера:** серверный синтез не нужен.
- **Ключ Gemini** хранится только в переменных окружения хостинга или в браузере пользователя, в репозиторий не попадает.
- **CSV вместо БД:** файл виден и открывается в Excel; правка и удаление переписывают его атомарно.

## Публикация (Docker, Render)

`Dockerfile` готов (Render, Railway, Hugging Face Spaces). Render: New → Web Service → репозиторий → Runtime Docker → Free,
регион Frankfurt; в Environment добавьте секрет `GEMINI_API_KEY`. Порт берётся из `PORT`. В образ ставится faster-whisper с моделью `base`.
Бесплатный план «засыпает» без запросов (первый заход после паузы — около минуты, за это время работает автономный режим)
и теряет файл данных при перезапуске — записи восстанавливаются из копии на устройстве пользователя.
