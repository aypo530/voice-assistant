🔑 Ключ GigaChat API

С ключом ассистент понимает речь и запросы намного точнее. Ключ хранится только в вашем браузере и отправляется на сервер вместе с запросами. Нужен ключ авторизации проекта GigaChat API: developers.sber.ru → Настройка API → «Получить ключ». Это длинная строка Base64, а не Client ID.

Можно пропустить: тогда ассистент использует ключ сервера (если он задан) или работает локально, без облака. GigaChat работает из России без VPN; если он станет недоступен, ассистент сам продолжит локально.
